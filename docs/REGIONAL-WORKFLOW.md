# Regional website workflow

1. The regional lead opens `/questionnaire`, completes identity, desired logo path, palette, hero direction, local copy, modules, and files, then copies the generated prompt.
2. The central owner downloads the generated Codex website prompt and asset package from the private owner inbox.
3. The central owner attaches this Kudihub source package and the regional submission to Codex, then uses the generated prompt to build the distinct frontend.
4. Codex publishes a free review link. The regional lead reviews desktop/mobile, logo, language, copy, and module choices. They do not need source code or a developer environment.
5. After approval, the central owner exports the regional source package and sends it to the development team.
6. Development connects production authentication, database/storage, social APIs, domain, analytics, and audited staking contracts.
7. After launch, regional managers sign in to publish Journal articles, edit visible text, and switch optional modules between live/set-up-later/hidden.

## Logo file specification

- Master horizontal logo: editable SVG.
- Square symbol: editable SVG plus transparent PNG at 1024×1024 and 512×512.
- Separate light- and dark-background versions.
- Wordmark spelling must be final; all artwork must be licensed for the project.
- Symbol should remain recognizable at 24px and avoid tiny details.

The creator can also generate an automatic production logo prompt when a regional lead chooses “Create it for me.”
